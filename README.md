# Avidité — Le Dé du Jugement

Roguelike 3D "push your luck" en vue première personne. Explorez des salles
procédurales, prenez des risques avec le Dé du Jugement, croisez des PNJ
marchands, et amassez de l'or à travers 8 zones visuelles distinctes.

Anciennement développé dans le monorepo [JulGame](../ruine), séparé en projet
indépendant le 2026-08-29.

## Lancer le jeu

Nécessite un petit serveur HTTP local (voir `.claude/launch.json`) :

```bash
python -m http.server 5507
```

Puis ouvrir `http://localhost:5507`.
